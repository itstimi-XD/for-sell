## 사전 준비

### 계정 생성

#### Apple Developer Program
1. [Apple Developer](https://developer.apple.com) 가입
2. **연간 비용**: $99 USD
3. 필요 정보:
   - Apple ID
   - 신용카드 정보
   - 2단계 인증 설정

#### Google Play Console
1. [Google Play Console](https://play.google.com/console) 가입
2. **일회성 비용**: $25 USD
3. 필요 정보:
   - Google 계정
   - 신용카드 정보

### Expo 계정
```bash
# EAS CLI 설치
npm install -g eas-cli

# Expo 로그인
eas login

# 프로젝트 설정
eas build:configure
```

## iOS 앱스토어 배포

### 1단계: 앱 아이콘 및 스플래시 스크린 준비

#### 필요한 에셋:
- **앱 아이콘**: 1024x1024 PNG (투명도 없음)
- **스플래시 스크린**: 1242x2688 PNG

온라인 도구 추천:
- [AppIcon.co](https://appicon.co) - 앱 아이콘 생성
- [Canva](https://canva.com) - 디자인 도구

#### 아이콘 배치:
```bash
PomodoroTimer/
  └── assets/
      ├── icon.png (1024x1024)
      ├── splash-icon.png
      └── adaptive-icon.png
```

### 2단계: iOS 빌드 생성

```bash
# iOS 빌드 (클라우드에서 자동 빌드)
eas build --platform ios --profile production

# 빌드 진행 상황 확인
# 약 10-20분 소요
```

빌드가 완료되면 `.ipa` 파일이 생성됩니다.

### 3단계: App Store Connect 설정

1. [App Store Connect](https://appstoreconnect.apple.com) 접속
2. "내 앱" → "+" → "새로운 앱" 클릭

## 앱 판매 프로세스

### 앱이 가치 있으려면

#### 핵심 지표:
1. **다운로드 수**
   - 최소: 10,000+
   - 이상적: 100,000+

2. **활성 사용자 (DAU/MAU)**
   - DAU: 1,000+
   - MAU: 10,000+
   - DAU/MAU 비율: 10% 이상

3. **평점**
   - 최소: 4.0+
   - 이상적: 4.5+
   - 리뷰 수: 100+

4. **수익**
   - 월간 수익: $100+
   - 연간 수익: $1,000+

5. **성장률**
   - 월간 성장: 10%+
   - 꾸준한 상승 추세

### 앱 판매 플랫폼

#### 1. Flippa
- 웹사이트: https://flippa.com
- 수수료: 판매가의 10%
- 평균 판매가: $5,000 - $50,000

#### 2. Empire Flippers
- 웹사이트: https://empireflippers.com
- 수수료: 15%
- 고가 앱 전문 ($50,000+)

#### 3. AppBusinessBrokers
- 모바일 앱 전문
- 수수료: 협의

#### 4. FE International
- 고가 앱/SaaS 전문
- 최소 판매가: $1,000,000

### 앱 가치 평가

#### 일반적인 공식:
```
앱 가치 = 연간 순수익 × 2~3배
```

예시:
- 월 수익 $500 → 연 $6,000 → 가치 $12,000~$18,000
- 월 수익 $2,000 → 연 $24,000 → 가치 $48,000~$72,000

#### 가치를 높이는 요소:
- 꾸준한 수익 기록 (6개월 이상)
- 높은 사용자 유지율
- 성장 추세
- 깨끗한 코드베이스
- 상세한 문서
- 자동화된 프로세스
