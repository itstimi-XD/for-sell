# 포모타임 - 뽀모도로 타이머 앱

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-iOS%20%7C%20Android-lightgrey.svg)

집중력을 높이는 가장 쉬운 방법! 뽀모도로 기법을 활용한 생산성 타이머 앱입니다.

## 주요 기능

### 핵심 기능
- **25분 집중 타이머**: 뽀모도로 기법의 핵심, 25분 집중 세션
- **휴식 타이머**: 5분 짧은 휴식, 15분 긴 휴식
- **자동 알림**: 타이머 완료 시 푸시 알림
- **통계 추적**: 오늘/전체 완료한 뽀모도로 세션 카운트
- **직관적인 UI**: 모드별 색상 구분 (빨강: 집중, 청록: 짧은 휴식, 파랑: 긴 휴식)

### UI/UX 특징
- 모던하고 깔끔한 디자인
- 부드러운 애니메이션
- 시각적 진행 바
- 모드별 색상 테마
- 간편한 터치 컨트롤

### 생산성 도구
- 4개 뽀모도로 완료 후 자동으로 긴 휴식 제안
- 일일/전체 통계 자동 저장
- 앱을 닫아도 타이머 계속 실행
- 백그라운드 알림 지원

## 시작하기

### 필요 사항
- Node.js 14 이상
- npm 또는 yarn
- Expo CLI
- iOS 시뮬레이터 (macOS) 또는 Android 에뮬레이터
- 실제 테스트를 위한 Expo Go 앱 (선택사항)

### 설치 및 실행

1. **의존성 설치**
```bash
npm install
```

2. **개발 서버 시작**
```bash
npm start
```

3. **플랫폼별 실행**
```bash
# iOS (macOS에서만)
npm run ios

# Android
npm run android

# 웹
npm run web
```

### 실제 기기에서 테스트

1. 앱스토어 또는 플레이스토어에서 **Expo Go** 앱 설치
2. `npm start` 실행 후 나오는 QR 코드를 Expo Go 앱으로 스캔
3. 앱이 자동으로 로드됩니다!

## 앱스토어 배포 가이드

### iOS 앱스토어 배포

#### 1. EAS Build 설정
```bash
npm install -g eas-cli
eas login
eas build:configure
```

#### 2. iOS 빌드 생성
```bash
eas build --platform ios
```

#### 3. App Store Connect 제출
1. [App Store Connect](https://appstoreconnect.apple.com) 접속
2. 새 앱 생성
3. 앱 정보 입력:
   - **앱 이름**: 포모타임 - 뽀모도로 타이머
   - **부제목**: 집중력 향상 생산성 타이머
   - **카테고리**: 생산성
   - **설명**:
   ```
   뽀모도로 기법으로 집중력을 높이세요!

   포모타임은 25분 집중, 5분 휴식의 뽀모도로 기법을 쉽게 실천할 수 있는 앱입니다.

   주요 기능:
   - 25분 집중 타이머
   - 5분/15분 휴식 타이머
   - 완료 알림
   - 일일/전체 통계
   - 직관적이고 아름다운 UI

   생산성을 높이고 싶다면 지금 바로 시작하세요!
   ```

4. 스크린샷 업로드 (필요시 생성)
5. EAS Build에서 생성된 빌드 제출

#### 4. 심사 제출
```bash
eas submit --platform ios
```

### Android 플레이스토어 배포

#### 1. Android 빌드 생성
```bash
eas build --platform android
```

#### 2. Google Play Console 제출
1. [Google Play Console](https://play.google.com/console) 접속
2. 새 앱 만들기
3. 앱 정보 입력:
   - **앱 이름**: 포모타임 - 뽀모도로 타이머
   - **간단한 설명**: 집중력 향상을 위한 뽀모도로 타이머
   - **자세한 설명**:
   ```
   뽀모도로 기법으로 집중력을 높이세요!

   포모타임은 25분 집중, 5분 휴식의 뽀모도로 기법을 쉽게 실천할 수 있는 타이머 앱입니다.

   ✨ 주요 기능
   • 25분 집중 타이머 - 완벽한 집중 시간
   • 5분/15분 휴식 타이머 - 적절한 휴식
   • 푸시 알림 - 타이머 완료 시 자동 알림
   • 통계 추적 - 일일/전체 완료 세션 기록
   • 직관적인 UI - 모드별 색상 구분

   🎯 이런 분들께 추천합니다
   • 집중력을 높이고 싶은 학생
   • 생산성을 향상시키고 싶은 직장인
   • 시간 관리를 효율적으로 하고 싶은 프리랜서
   • 뽀모도로 기법을 실천하고 싶은 모든 분

   지금 바로 다운로드하고 생산성을 높여보세요!
   ```
   - **카테고리**: 생산성
   - **태그**: 뽀모도로, 타이머, 집중, 생산성, 시간관리

4. AAB 파일 업로드 (EAS Build에서 생성)
5. 심사 제출

```bash
eas submit --platform android
```

## 수익화 전략

### 1. 프리미엄 기능 (향후 추가 가능)
- 커스텀 타이머 설정
- 다양한 테마/색상
- 상세 통계 및 차트
- 백업/동기화 기능
- 위젯 지원

### 2. 광고
- Google AdMob 통합
- 배너 광고 (하단)
- 리워드 광고 (프리미엄 기능 무료 체험)

### 3. 앱 판매
- 사용자 기반이 확보되면 앱 자체를 판매
- 월간 활성 사용자(MAU) 지표가 중요
- 평점과 리뷰 관리 필수

## 마케팅 전략

1. **ASO (앱 스토어 최적화)**
   - 키워드: 뽀모도로, 타이머, 집중, 생산성, 시간관리
   - 매력적인 아이콘과 스크린샷
   - 정기적인 업데이트

2. **초기 사용자 확보**
   - Reddit, ProductHunt 등에 소개
   - SNS 홍보 (인스타그램, 트위터)
   - 블로그 포스팅

3. **리뷰 관리**
   - 앱 내 리뷰 요청 기능 추가
   - 사용자 피드백 적극 반영
